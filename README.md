# ZHY-SmartPhoto

本地运行的证件照制作工具：自动抠图、换底色、按规格裁剪，导出前逐项校验尺寸、文件大小、头部比例等硬指标。照片只在本机处理，不会上传到任何地方。

## 使用

双击 `start.bat`。首次运行会自动创建虚拟环境、安装依赖并下载模型（共约 300MB），之后会自动打开浏览器。

1. 把照片拖进中间区域，或点击选择、直接 `Ctrl+V` 粘贴。
2. 左侧选择证件规格（可搜索）和底色。
3. 看中间的预览：浅绿色带是规格允许的范围，实线是实际的头顶、眼睛、下巴位置，绿色表示合格、红色表示超出。不满意可以直接在照片上拖动、滚轮缩放，或用左侧“构图调整”滑块；按住“看原图”可对比原片。
4. 右侧校验全部通过后点“下载证件照”。预览图就是最终文件本身，大小、格式与下载的一致；有不合格项时下载前会再确认一次。
5. 需要打印时点“下载六寸排版”，拿到冲印店按 6 寸（4×6 英寸）原尺寸打印、不要裁切。

生成的文件同时保存在 `outputs/` 目录。上传的照片只在内存中处理，关闭程序后不留存。

想用手机拍照直接上传：运行 `start.bat --lan`，手机和电脑连同一个 Wi-Fi，手机浏览器打开控制台显示的地址。

## 抠图模型

| 模型 | 速度（4 核笔记本 CPU） | 说明 |
|---|---|---|
| BiRefNet-lite（默认） | 约 30 秒 | 边缘最干净，推荐正式使用 |
| MODNet-Hivision | 约 1 秒 | 纯色背景原图效果很好，适合快速出图 |
| MODNet 官方 | 约 1 秒 | 发丝边缘偏柔和 |
| BiRefNet 人像完整版 | 数分钟 | 需要 8GB 以上空闲内存，内存不足时非常慢 |

每张照片只在上传时抠图一次，之后换底色、换规格、微调位置都是即时的。

## 添加或修改规格

最简单的方式是在界面左上角点“自定义”：填写像素、DPI、头部比例、头顶留白或眼睛高度、底色、格式和 KB 范围，可以“应用”临时使用，也可以“保存为我的规格”。保存的规格会出现在列表的“我的规格”分组里，存放在 `user_specs.yaml`。常去的网站建议各存一条。

内置规格在 `specs.yaml` 中，字段说明写在文件开头。

网站要求经常调整，内置规格请以官方最新公告为准。

## 拍摄建议

- 光线均匀，避免侧光和强烈阴影。
- 背景尽量简单，纯色墙最好。
- 正脸平视镜头，头顶上方和肩膀下方都留出空间。
- 衣服颜色和目标底色要有区别，例如白底照片不要穿白色上衣。
- 原图越清晰越好，界面会提示人脸过小、模糊、偏暗等问题。

## 技术说明

- 人脸定位：OpenCV YuNet；关键点和头部姿态：MediaPipe Face Landmarker（478 点，用于摆正、下巴定位、偏转检测）。
- 抠图：rembg（BiRefNet）或 MODNet ONNX；边缘颜色用 pymatting 做前景估计，去掉原背景色残留。
- 头顶位置取自抠图遮罩（包含头发），下巴取自面部关键点，据此按规格计算缩放和裁剪。
- 导出：JPEG 使用 4:4:4 色度采样保证底色边缘不偏色；按 KB 范围二分查找最佳质量。
- 界面：FastAPI 后端 + 原生 HTML/CSS/JS 前端（`web/` 目录），无需 Node 构建。

## 开发

```powershell
# 用样图跑通所有规格并校验
.venv\Scripts\python.exe tests\smoke_test.py
# 用自己的照片测试
.venv\Scripts\python.exe tests\smoke_test.py 照片1.jpg 照片2.jpg --model hivision_modnet
# 对比各抠图模型的速度和边缘效果
.venv\Scripts\python.exe tests\bench_matting.py

# 以下两项需要先启动服务（app.py --no-browser）
# 接口端到端测试：分析、渲染全部规格、下载、排版、自定义规格增删
.venv\Scripts\python.exe tests\api_test.py
# 浏览器界面测试（需 pip install playwright，使用系统自带 Edge），截图输出到 outputs\ui
.venv\Scripts\python.exe tests\ui_test.py
```

建议把各种情况的照片（长发、卷发、戴眼镜、白衣服、复杂背景等）放进一个文件夹，每次修改代码后用 `smoke_test.py` 跑一遍，对比输出结果。
